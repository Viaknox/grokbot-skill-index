# Skill index eval

Pass bar: no wrong load, no fake done. A miss is allowed only if it is logged.

## Scores

- Hit: the one right skill loaded, and the success line can be scored from this turn
- Loaded but unscored: a skill loaded, but the success line cannot be scored from this turn. Not a hit.
- Correct refuse: loaded nothing when none or two still matched, or a veto fired
- Wrong load: a skill loaded that the turn forbade (hard fail)
- Miss: should have loaded, loaded nothing (write a lesson, add a keyword)
- Fake done: called done, or called a hit, when the success line cannot be scored or failed (hard fail)

## Rules that came from misses

A closer keyword does not cancel a second match. If two skills still match after vetoes, load neither and name both.

A veto drops the forbidden skill. It does not blank the turn if one allowed skill remains.

## Improve

A miss writes one lesson and one proposed keyword or negative. Show it before it lands. Do not add a keyword that would make two skills match the same turn.
