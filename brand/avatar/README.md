# Tune-Up

Tune-Up by Viaknox is the product and the Grok bot; the raven is Tune-Up: goggles up, spanner in one claw, an index card in the other, standing on the toolbox (the skill library).

| File | Use |
|---|---|
| `tune-up-sticker-*.png` | **Bot avatar / profile image.** Transparent, with a Paper outline so it reads on dark and light (Grok's dark UI included). |
| `tune-up-transparent-*.png`, `tune-up.svg` | Transparent, no outline. Light backgrounds only — the Petrol raven disappears on dark. |
| `tune-up-avatar-circle-1024.png` | Raven on a Paper circle, for places that crop avatars round. |
| `tune-up-avatar-tile-1024.png` | Raven on the Paper rounded tile (same as the app icon). |

Rules: same as the Tune-Up mark — never redraw, recolour or crop the raven; never on a Tangelo disc or inside City art.
