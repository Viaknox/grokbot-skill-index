# Tune-Up icon

The raven on its Paper rounded tile. Works on light and dark backgrounds.

| File | Use |
|---|---|
| `icon.png` (512 px) | Repo root / plugin icon |
| `tune-up-icon.svg` | Any size |
| `tune-up-icon-{16…1024}.png` | Fixed sizes; 16–32 px use the head crop so it stays readable |
| `tune-up-icon-180.png` / `-192.png` | Apple touch icon / Android home screen |
| `favicon.ico` | 16, 32, 48 px |

For the Grok bot's profile picture use `../avatar/tune-up-sticker-512.png` instead (no tile, cream outline).
